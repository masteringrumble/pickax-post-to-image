# Browser extension — build, test, package

## Layout

```
extension/
  manifest.json      # MV3, one file for Chrome / Edge / Opera / Firefox
  background.js      # toolbar button -> picker mode; picked posts -> open web app pre-filled
  content.js         # runs on pickax.com/*, uBlock-style post picker + post payload extraction
  icons/             # 16 / 32 / 48 / 128 px (generated by make_icons.py) + logo.svg for the card header
  make_icons.py      # regenerate icons
  test-content.cjs   # jsdom smoke test for content.js extraction + picker
  package.sh         # builds the store-ready zip
  PRIVACY.md         # privacy policy (link this in store listings)
  STORE_LISTING.md   # store copy + publishing checklist
```

Picker flow: clicking the toolbar button on any pickax.com page puts the tab
in picker mode — hover a post card to highlight it, click it, and the web
app opens with that post pre-filled, so people get the same options as the
website (image toggles, site embed, etc.). Esc cancels. No buttons are
injected into posts. On non-Pickax pages the toolbar button just opens the
web app.

## Test

```sh
NODE_PATH=./node_modules node extension/test-content.cjs
node --check extension/content.js && node --check extension/background.js
```

## Package

```sh
./extension/package.sh
# -> dist-ext/pickax-post-to-image-extension-1.0.0.zip
```

The zip contains `manifest.json`, `background.js`, `content.js`, `icons/`
at the top level — the layout every store expects. The same zip uploads to
all four stores.

## Load unpacked (sideload, any Chromium browser)

1. Open `chrome://extensions` (Edge: `edge://extensions`, Brave:
   `brave://extensions`, Opera: `opera://extensions`).
2. Enable **Developer mode**.
3. **Load unpacked** → select the `extension/` folder.

Firefox (temporary, for testing): `about:debugging` → This Firefox →
Load Temporary Add-on → pick `manifest.json`. For permanent installs Firefox
requires a Mozilla-signed build (see STORE_LISTING.md, AMO unlisted).

## Versioning

Bump `version` in `manifest.json` for every store update (stores reject
re-uploads with the same version). Keep it in sync with the git tag
`extension-vX.Y.Z` used for the GitHub release.
